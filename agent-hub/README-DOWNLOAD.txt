Foresite Agent Hub — downloaded copy

Windows
  1. Install Node.js LTS from https://nodejs.org (click Next through the installer).
  2. Unzip this file anywhere, open the agent-hub folder, double-click start-windows.cmd.
  3. The console opens in your browser at http://localhost:4747. Paste your API keys in the Connect tab.

Mac
  1. Install Node.js LTS from https://nodejs.org.
  2. Unzip, open the agent-hub folder, right-click start-mac.command and choose Open.

Voice: click the microphone in the console and allow the browser to use it (Chrome or Edge). The hub
transcribes with your OpenAI key, so connect ChatGPT first.

Keys stay in agent-hub/.env on this computer only. This copy does not update itself; the one-paste
installer (install-windows.ps1 / install-mac.sh) does, when you have access to the GitHub repository.
