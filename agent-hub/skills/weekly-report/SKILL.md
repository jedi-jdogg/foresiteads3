# Weekly client report

Use this when Jonathan asks for a weekly report, Monday numbers, or a client update.

1. Pull last week and the week before from the connected sources: Shopify (`shopify__sales_summary`), Klaviyo, Meta Ads, Google Ads and Triple Whale if connected. Use the same 7-day windows for both.
2. Lead with the four numbers the client cares about: revenue, orders, blended ROAS (or MER), new customers. Show each as this week, last week, and the change.
3. Explain the change in two or three sentences. Name the channel or campaign that moved it. No filler.
4. List what we did last week (campaign changes, emails sent, tests started).
5. List next week's actions, three at most, each with an owner and a date.
6. Keep it under 250 words. Plain text, ready to paste into an email. Sign off as Foresite Ads.

If a source is not connected, say which numbers are missing rather than estimating them.
