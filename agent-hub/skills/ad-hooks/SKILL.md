# Ad hooks

Use this for "hooks", "first lines", "openers" or "ad angles".

1. Ask yourself who the ad is for and the one problem it solves. If the request does not say, take the most likely e-commerce buyer for the product and state that assumption in one line.
2. Write ten hooks, under twelve words each, across these angles: problem, curiosity, social proof, offer, objection, identity, before/after, how-to, contrarian, urgency.
3. For each hook add the first visual frame in a few words.
4. Mark the one to test first and say why in one sentence.
5. No emojis, no exclamation marks, no "Introducing".
